# Человек или нейронка

20 текстов из `data/original.json` и `data/news3-astra.json`, случайный порядок без повторов. Авторство раскрывается только в итоговой таблице. Ответы хранятся в памяти текущей страницы; обновление начинает новый тест.

```sh
npm install
npm run build
npm start
```

Открыть http://127.0.0.1:43871. `npm run lint` проверяет TypeScript. Сборка обновляет тексты из исходных JSON, проверяет пустые тексты и дубликаты. Для публикации используется только `dist`, без остальных материалов родительского проекта.

## Публикация

Сайт: https://tadatuta.github.io/slope-or-not/

Исходники — ветка `main`, готовый сайт — `gh-pages`. После изменений запустите `npm run build`, проверьте `npm run lint` и опубликуйте содержимое `dist` в корень `gh-pages`. В настройках GitHub Pages выберите Deploy from a branch → gh-pages → / (root).
